RabbitMQ is exposed through fixed NodePorts intended for a kind cluster created with the repository's kind-config.yaml.

Management UI:
  https://localhost:{{ .Values.service.management.port }}

AMQPS:
  amqps://{{ .Values.auth.username }}:{{ .Values.auth.password }}@localhost:{{ .Values.service.amqps.port }}

If your browser or client does not trust the self-signed certificate yet, install the CA locally:
  ./scripts/trust-local-ca.sh

If you want to replace the chart-generated certificate with an OpenSSL-generated one:
  ./scripts/generate-tls-secret.sh
  helm upgrade --install {{ .Release.Name }} charts/rabbitmq-cluster --namespace {{ .Release.Namespace }} --create-namespace --set rabbitmq.tls.existingSecret={{ .Release.Name }}-rabbitmq-cluster-tls-local

If localhost access is not working, recreate kind with the repository's kind-config.yaml so host ports 5671 and 15671 map to the service NodePorts.
